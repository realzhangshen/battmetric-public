# Security policy

Please do not disclose suspected vulnerabilities or sensitive diagnostic
information in a public Issue.

Use GitHub's private vulnerability-reporting feature for this repository. If
that option is unavailable, open a public Issue containing no vulnerability
details and ask the maintainers for a private reporting channel.

For a report about a published build, include the affected BattMetric version,
operating system, architecture, and non-sensitive reproduction information.
Do not include license keys, credentials, personal information, research data,
or unredacted system logs.

Only files published on this repository's Releases page should be treated as
official BattMetric downloads. Verify the checksum and any platform signature
documented for the release before installation.
